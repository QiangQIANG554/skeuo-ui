# 设计原则

Skeuo UI 是一套**纯正 Neumorphism（新拟物）**风格的 Vue3 组件库。视觉语言由以下原则定义。

## 核心：双向柔和阴影

新拟物最本质的特征是**同一背景色上同时存在亮影与暗影**：

- 背景：`#f7f6f2`（微暖白）
- 表面：`#ffffff`（纯白）
- 凸起：左上亮影 + 右下暗影（`--s-shadow-raised`）
- 凹陷：inset 反转（`--s-shadow-inset`）

```
凸起（按钮/卡片）          凹陷（输入框/轨道）
┌──────────┐              ┌──────────┐
│ 亮↖ 暗↘  │              │ 暗↖ 亮↘  │
└──────────┘              └──────────┘
```

## 禁用的东西

- ❌ 边框（用阴影替代）
- ❌ 渐变（纯色背景）
- ❌ 纹理/噪点
- ❌ 发光效果（激活态用纯色变化，不用 box-shadow 发光）

## Token 体系

所有样式通过 CSS 变量定义（`--s-*`），支持浅色/深色双套：

| Token | 浅色 | 用途 |
| --- | --- | --- |
| `--s-bg` | `#f7f6f2` | 页面背景（也是凹陷面） |
| `--s-surface` | `#ffffff` | 表面（凸起面） |
| `--s-ink` | `#333` | 主文字 |
| `--s-primary` | `#5f86a8` | 主色（低饱和蓝） |
| `--s-success` | `#6ba3a0` | 成功 |
| `--s-danger` | `#c96f4a` | 危险 |
| `--s-shadow-raised` | `8px 8px 16px #d9d7d1, -8px -8px 16px #fff` | 凸起阴影 |
| `--s-shadow-inset` | `inset 6px 6px 12px #d9d7d1, inset -6px -6px 12px #fff` | 凹陷阴影 |

## 圆角与字体

- 圆角：`--s-r-sm 8px` / `--s-r-md 14px` / `--s-r-pill 999px`
- 正文字体：系统字体栈（`--s-font`）
- 数字/标题：衬线体（`--s-font-serif`，数字 tabular-nums）

## 交互约定

- 拟物元素**按下才动**（阴影收缩/内凹），不追求位移动画
- 过渡统一 0.12~0.25s ease
- 激活/选中态 = 凹陷或纯色填充，不用发光
