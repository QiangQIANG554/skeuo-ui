# 文本域

多行文本输入，组件名 `Textarea`，前缀 `S`。

## 基本用法

```vue
<template>
  <Textarea />
</template>

<script setup lang="ts">
import { Textarea } from 'skeuo-ui'
</script>
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | `string` | '' |  |
| `placeholder` | `string` | '' |  |
| `disabled` | `boolean` | false |  |
| `rows` | `number` | 4 |  |
