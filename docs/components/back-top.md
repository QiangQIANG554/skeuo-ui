# 回到顶部

快速回顶，组件名 `BackTop`，前缀 `S`。

## 基本用法

```vue
<template>
  <BackTop />
</template>

<script setup lang="ts">
import { BackTop } from 'skeuo-ui'
</script>
```

| 属性 | 类型 | 默认值 | 说明 |

| `bottom` | `number` | 48 |  |
