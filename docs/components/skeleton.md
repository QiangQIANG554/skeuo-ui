# 骨架屏

加载占位，组件名 `Skeleton`，前缀 `S`。

## 基本用法

```vue
<template>
  <Skeleton />
</template>

<script setup lang="ts">
import { Skeleton } from 'skeuo-ui'
</script>
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `rows` | `number` | 3 |  |
| `animated` | `boolean` | true |  |
| `avatar` | `boolean` | false |  |
| `title` | `boolean` | true |  |
| `width` | `string` | '100%' |  |
