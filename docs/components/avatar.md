# 头像

用户头像，组件名 `Avatar`，前缀 `S`。

## 基本用法

```vue
<template>
  <Avatar />
</template>

<script setup lang="ts">
import { Avatar } from 'skeuo-ui'
</script>
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `src` | `string` | '' |  |
| `alt` | `string` | '' |  |
| `text` | `string` | '' |  |
| `size` | `number | string` | 40 |  |
| `shape` | `'circle' | 'square'` | 'circle' |  |
